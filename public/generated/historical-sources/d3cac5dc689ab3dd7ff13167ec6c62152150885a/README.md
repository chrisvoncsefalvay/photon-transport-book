# Historical public package sources

These 70 files preserve the public package source and dependency-lock bytes used by the transmission and pose-sensitivity figures. They were recovered from commit `d3cac5dc689ab3dd7ff13167ec6c62152150885a` and checked against the original run hashes and Git blobs.

`provenance.json` maps distributed sources to their paths and digests. Its `private_sources` records retain the original identities and hashes of 9 experiment producer files held in the private authoring archive. Those producers are not distributed here. Figure manifests check all distributed source and output bytes, and retain separate hashes for the private producers.

The figures, numerical arrays and original run records are unchanged. Use the current `python/dpt` package for the textbook implementation; this directory preserves historical source identity.
